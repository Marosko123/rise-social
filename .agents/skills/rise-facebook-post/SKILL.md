# Rise Facebook post

Write a useful company update for a broad audience in plain Slovak. It must feel
like a calm explanation from Rise, not a shortened LinkedIn post.

## Inputs

Read the approved brief, `brand/voice.sk.json`, claim evidence and previous Facebook
openings. Decide whether the post is an update, a practical insight or a project
story. Identify the one fact or consequence people should remember.

## Copy sequence

1. State the actual update, result of work or useful observation.
2. Explain why it matters in one short conversational paragraph.
3. Add a verified HTTPS link only when a web visit is the objective.
4. Finish naturally. A question or request for comments is never mandatory.

Aim for no more than 900 characters. Use 0–2 controlled hashtags and at most one
natural emoji. Avoid corporate launch language, long unrelated captions, hidden
claims and copied LinkedIn formatting.

## Visual sequence

Use ordered images that remain understandable without carousel controls. The first
image carries the topic. Prefer a smaller, clearer selection over uploading every
LinkedIn page. Keep the image order intentional and verify the mobile preview.

## Trust checks

Numbers, savings, client results and named people require approved evidence. Never
use a low-quality landing page, misleading promise or long caption unrelated to the
media. A direct link gets the Facebook UTM only after its final destination passes
an HTTPS check.

## Output contract

Return a locally understandable Facebook caption under 900 characters, 0–2 hashtags, a smaller
ordered image selection whose first image carries the topic and an optional verified direct link.

## Stop conditions

Stop on an unsupported result, the old `School` category or outdated Rise profile
context, a generic announcement, engagement bait, an unverified URL or media that
does not match the caption.

## Pressure test

Good: a short project observation and two ordered explanatory images are appropriate. Bad: a
compressed LinkedIn essay or a caption unrelated to the first image is rejected.
