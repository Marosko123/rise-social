# Rise Instagram post

Build one visual explanation people can understand by swiping. The caption supplies
context; it does not repeat every slide.

## Inputs

Read the approved brief, `brand/voice.sk.json`, claim evidence, prior Instagram
openings and the current 3×3 preview. Select authentic product UI, a verified team
photo or a branded diagram. Generative imagery requires explicit approval.

## Carousel sequence

1. Cover: name the concrete benefit or question the slides actually answer.
2. Context: show the real situation without a vague hook.
3. Explanation: one idea, step or contrast per slide.
4. Evidence: connect factual slides to claim IDs.
5. Close: summarize the decision or next useful step without engagement bait.

Use 4–8 slides at 1080×1350 px with shared orientation, safe margins, accessible
contrast and slide numbering. Each tile must work alone in the profile grid. Never
create a puzzle grid. Write specific alt text for each image.

## Caption sequence

1. One concrete first sentence.
2. Two to four short sentences that add context unavailable on the slides.
3. Use `odkaz v profile` only when a web visit is the objective.
4. End with 2–5 controlled topic hashtags.

Do not place a raw URL in the caption. Do not use emoji as bullets. One emoji is
allowed only for a natural event. Confirm all slides still make sense after the
order is fixed because Instagram cannot reorder published carousel items.

## Grid review

Inspect the cover as a single tile and inside the latest 3×3 grid. Check title size,
edge cropping, repetition of neighbouring colours and whether the topic remains
clear without reading the caption.

## Output contract

Return an Instagram-first 1080×1350 carousel, per-slide alt text, standalone grid-tile check,
short contextual caption, 2–5 controlled hashtags and `odkaz v profile` only for a visit goal.

## Stop conditions

Stop on a clickbait cover, raw caption URL, missing alt text, unreadable mobile type,
more than one idea per slide, fragile puzzle layout, uncertain media rights or an
unsupported claim.

## Pressure test

Good: a seven-slide Decision Note explains one choice and its trade-offs visually. Bad: the
LinkedIn caption copied below the same slides, or a raw URL, must be rewritten.
